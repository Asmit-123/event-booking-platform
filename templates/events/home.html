How it works

1. Organizers publish

Create an event with a date, a venue and a seat limit. Edit or cancel it any time before it starts.

2. Attendees register

Browse upcoming events, see how many seats are left, and take one. Each person gets one seat per event.

3. Seats stay honest

The seat limit is enforced by the server even when many people register at once.
